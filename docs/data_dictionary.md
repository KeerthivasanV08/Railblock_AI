# RailBlock AI — Data Dictionary & Provenance Classification

This document provides a canonical data dictionary and explicit provenance classification for all primary datasets in the RailBlock AI system.

## Data Provenance Classifications

1. **REAL**: Directly sourced from official public databases, Indian Railways Open Government Data (OGD), or CAG audit reports.
2. **DERIVED**: Calculated or translated by spatial/network algorithms using real base geographic geometry or station chainage.
3. **SYNTHETIC**: Generated by domain-grounded simulation algorithms representing operational maintenance tasks, defects, or machine availability for demonstration and modeling.
4. **REFERENCE**: Static domain standards, lookup maps, or audit evidence benchmarks.

## Metric Semantic Definitions

- **Scheduled Trains Per Day**: Number of scheduled passenger and freight services passing through the corridor per 24-hour cycle.
- **Active Trains**: Number of trains operating within the simulated corridor time window.
- **Corridor Asset Availability**: Percentage of total section-minutes available for train movements (`(1.0 - (total_possession_minutes / total_section_minutes)) * 100`).
- **Section Seasonal Risk Score (SRS)**: Composite risk score `[0.0, 100.0]` calculated deterministically as `(season_score * Ws + vuln_score * Wv + live_severity * Wl) * asset_multiplier`.
- **Weather Maintenance Suitability**: Bounded score `[0.0, 1.0]` representing environmental safety and execution suitability (`1.0 - combined_weather_risk`).
